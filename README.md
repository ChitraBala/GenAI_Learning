# Student Grade System

A simple Python program that takes a student's mark between **0 and 100** and displays the corresponding letter grade.

## Grading Scale

| Mark | Grade |
|------|-------|
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| Below 60 | E |

## Requirements

- Python 3
- No external packages or frameworks
- Uses only standard Python functionality
